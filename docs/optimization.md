# 最適化の検証記録

2026-09-07、ローカル環境（macOS / Python 3.12）で測定。
元データは `data/trade_data/ch*_2022.csv.gz` の24ブロック（gzip合計約21.7 MB）。
一時フォルダで年別に結合し、旧方式と新方式を別プロセスで各1回実行した。
計測範囲は3変数のCSV読み込み・集計で、年別結合の準備や出力保存は時間に含まない。
ピークメモリは各プロセスの `resource.getrusage().ru_maxrss`。

| 方式 | 時間 | ピークRSS |
|---|---:|---:|
| 旧：CSVを3回読み、年単位で全行保持 | 8.625秒 | 347.5 MB |
| 新：CSVを1回読み、10万行ずつ集約 | 3.106秒 | 146.4 MB |

この測定では時間は約64%、ピークメモリは約58%減少した。
3変数と品目数は `rtol=1e-10, atol=1e-6` で一致。
浮動小数点の合算順は変わるため、ビット単位の一致は要求していない。
単年・単回の結果であり、26年の通し実行やAPI取得の性能を表すものではない。
新方式も全期間の日本明細と集約済み市場を保持するため、メモリ使用量は対象期間に応じて増える。

再現コマンド：

```bash
python tests/benchmark_trade.py --source data/trade_data
python -m unittest discover -s tests -v
```

テストではチャンク境界にまたがる同一品目、年ごと・固定の品目集合、報告国除外、
World抽出の再実行、先頭ゼロと並び順、入力異常時の既存出力保護も確認する。

統合後の検証コードはローカルの `tests/` にのみ保持しています（Git対象外）。上記コマンドはそのローカル環境用です。
