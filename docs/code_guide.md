# コードを読む順番

最初は `02_analyze_trade.ipynb` を読み、必要に応じて共通関数の中を確認してください。
CSVの保存場所や対象年を変えるだけなら、`settings.py` とREADMEの説明で足ります。

## ファイルごとの役割

| ファイル | 読むポイント |
|---|---|
| `settings.py` | 対象年・フォルダの設定 |
| `02_analyze_trade.ipynb` | 日本の輸出額 → 世界の市場規模 → 日本の品目に限定した市場規模 |
| `02_analyze_trade.ipynb` | 3変数を結合 → EM/IMを計算 → 検算 → 保存 |
| `lib/trade_processing.py` | CSVを分割して読む共通処理。分析式から読み込みの詳細を分離 |
| `lib/prepare_yearly.py` | 入力の存在確認 → 1年ずつ結合 → 完成後に出力を置き換え |
| `tests/` | 小さな例で集計結果が正しいか確認するコード |

## 変数の名前と中身

| 名前 | 中身 |
|---|---|
| `files` | 年をキー、年別CSVのパスを値に持つ辞書 |
| `japan_rows` | 日本の輸出明細。Worldも含む |
| `japan_partner_rows` | 日本の輸出明細からWorldを除いた表 |
| `markets_by_year` | 年をキー、相手国×品目ごとの世界の輸出額を値に持つ辞書 |
| `year_market` | 1年分の市場集計表 |
| `exported_commodities` | 日本が輸出する相手国×品目の組。重複なし |
| `covered_market` | その組に該当する世界の輸出額 |
| `japancountry` / `worldcountry` / `japanx` | 出力CSVの列名にも使う分析変数。定義はREADMEを参照 |

## pandasの読み方

- `table.loc[条件]`：条件に合う行を選ぶ。
- `groupby(列)` と `sum()`：同じ年・国などの行をまとめて合計する。
- `merge(..., on=列)`：指定した列を手掛かりに2つの表を結合する。
- `drop_duplicates()`：同じ組を1つにまとめる。
- `pd.concat(...)`：複数の表を縦につなぐ。

`chunk` はCSVを一度に読む行のまとまりです。大量データを扱うための仕組みで、
分析上の「年」「国」「品目」とは別の単位です。同じ品目が複数チャンクに現れるので、
チャンク別の合計をさらに足し合わせています。

## 修正するときの方針

短いコードにすることより、処理の意味が追えることを優先します。
条件が長ければ `is_target_year` のように名前を付け、選別・結合・集計を別の段階にします。
コメントにはコードの読み上げよりも「なぜWorldを除くか」などの理由を書きます。

分析式はノートブックで確認できるように残し、繰り返す読み込み・保存は関数にまとめます。
出力CSVの列名や経済指標の名前は、既存の分析と対応できるように維持します。
修正後は `python -m unittest discover -s tests -v` で結果を確認してください。

`tests/` はローカル検証用でGitには含みません。データ準備の入口は `01_prepare_data.ipynb`、分析の入口は `02_analyze_trade.ipynb` です。
